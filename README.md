# Assignment-4

## Project Description
This project is a searchable TV show gallery created for CSC-372 Web Development at the University of North Carolina at Greensboro.

The website allows users to search for television shows using the TVmaze API. Matching shows are displayed in a responsive flex-style gallery with information about each show.

The website features a very Gilded Age-inspired design with an ivory background, burgundy show cards, and antique gold accents.

## Features
- Search for TV shows by title or keyword.
- Display up to 10 matching TV shows.
- Automatically display results for "Friends" when the page loads because that my personal favorite show.
- Display show titles, summaries, premiere dates, and last updated dates.
- Display genres and average ratings.
- Retrieve and display up to five main cast members and their characters using a second API request.
- Provide links to each show's TVmaze page.
- Handle empty searches, missing information, and API errors.
- Display TV shows in a responsive Flexbox layout.
